商品价格与库存监控器 V8.24 — XPS 配置扫描性能与库存读取修复

运行：在旧版点击“退出程序”，再运行 PriceStockMonitor_Win64_V8.24.exe。
旧商品设置与历史沿用；升级前会由应用备份已有数据。不要同时运行旧版。

修改：
- 本次运行内复用编译的 Windows 读取组件；读取前校验缓存内容，未知或已改变 DLL 重新编译。
- 没有实际确认操作时，省去额外 Windows 快照；实际配置变化仍重新读取并核对。
- 硬盘、屏幕从当前选项开始遍历，减少重置；不减少需要核对的组合。
- 内存选项在实际旧状态连续稳定至少10秒且3次读取仍未切换时，标记该分支未确认并继续。不会用旧配置冒充成功，也不会将未确认标为缺货。
- 已核对配置在扫描中逐步显示，历史和提醒仅在本轮结束后生成。编辑、删除或取消隔离迟到结果；最终提醒仍比较扫描前的基线。
- 购买栏因布局隐藏时，可只读核对同一当前 Offer 的唯一、未禁用、非加载购买按钮；从未执行加入购物车或购买。
- 当前可见总价恢复时，可接受独立核对的当前库存；仍不借用滞后的旧原价生成折扣。
- 诊断增加读取耗时、逐条定制报价/选项/库存状态和隐藏原因计数。

验证范围：
Go回归、Linux/Windows静态检查、Windows GUI交叉构建，以及真实Chromium中的本地页面模型配置点击、库存边界和实际应用界面测试。
当前云机器为Linux，无法执行Windows UIAutomation/PowerShell组件；真实Dell网络请求被代理拒绝。
测试记录中的40组合是本地模型，不代表网站当前有货数量。尚未证明Windows实机扫描完整或具体提速倍数。
Windows实机核对：运行本版、完成一轮XPS扫描、下载诊断。重点检查内存切换、可见有货结果、扫描耗时与未确认分支；如仍异常，使用新增诊断继续定位。
